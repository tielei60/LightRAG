# 北京人寿京福盈嘉终身寿险投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京福盈嘉终身寿险 |
| 销售渠道 | 个险、中介 |
| 可附加险种 | 无 |
| 交费方式 | 趸交、年交 |
| 交费年期 | 趸交、3年、5年、6年、10年、15年、20年 |
| 保险期间 | 终身 |
| 最低保费 | 1000元，且为1000元整数倍 |

## 二、投保规则

执行现有个险公共投保规则。交费方式、年期、保险期间、年龄及保费须符合以下条件：

| 交费年期 | 被保险人投保年龄 |
| --- | --- |
| 趸交 | 出生满28日（含）至75周岁（含） |
| 3年交 | 出生满28日（含）至72周岁（含） |
| 5年交 | 出生满28日（含）至70周岁（含） |
| 6年交 | 出生满28日（含）至69周岁（含） |
| 10年交 | 出生满28日（含）至65周岁（含） |
| 15年交 | 出生满28日（含）至60周岁（含） |
| 20年交 | 出生满28日（含）至55周岁（含） |

## 三、核保规则

### 1. 公共核保与加费

执行现有公共核保规则。不支持健康加费和职业加费。

### 2. 体检要求

| 被保险人年龄 | 需体检的条件 |
| --- | --- |
| 不满18周岁 | 同类险种累计应交总保费超过600万元 |
| 18—50周岁，含上下限 | 超过1500万元 |
| 51—65周岁，含上下限 | 超过1000万元 |
| 66—75周岁，含上下限 | 超过500万元 |

### 3. 财务要求

同类险种累计应交总保费超过1500万元，须提供财务问卷。

同类险种为所有增额终身寿险，包括京福传家、京福世享、京福传世爱、恒爱传世、京福悦享、京福多多、京福满满等系列。

应交总保费＝期交保费×交费期限。仅累计有效及在途保单，其他状态不累计。

## 四、风险保额累计

寿险、残疾风险保额分别＝本产品总应交保费×当前年龄身故倍比系数。仅累计有效及在途保单。

| 到达年龄 | 系数 |
| --- | --- |
| 0—17周岁 | 不计 |
| 18—40周岁 | 0.6 |
| 41—60周岁 | 0.4 |
| 61周岁及以上 | 0.2 |
