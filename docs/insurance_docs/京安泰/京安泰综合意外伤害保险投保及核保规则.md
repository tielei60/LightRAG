累计包括京安泰老版本产品的有效及在途保额。

| 被保险人年龄 | 限制 |

## 三、核保规则

### 1. 产品核保条件

- 公共交通意外累计风险保额不超过500万元。
- 个险渠道自驾车意外累计风险保额：北京、上海、广州、深圳不超过200万元；省会城市不超过150万元；地级城市不超过100万元；县城及以下不超过50万元。
- 意外医疗责任保额不超过基本责任保额的20%，且最高不超过10万元。
- 住院津贴日给付额不超过基本责任保额的0.1%；北京、上海、广州、深圳最高500元／天，省会城市最高300元／天，其他地区最高200元／天。

### 2. 公共核保规则的产品例外

执行现有个险公共核保规则，下列公共规则对本产品不适用；本产品自身的职业、责任及保额条件仍须满足：

- 投保人累计年交保费超过年收入20%的公共限制，包括有效期交保单累计年交保费的相关限制。
- 被保险人寿险职业等级不低于5级的公共限制。
- 单张短期意外险保费须不低于50元的公共限制。
- 五类职业累计意外风险保额超过50万元、六类职业超过30万元的公共限制。
- 按年龄与年收入倍数限制人身险风险保额的公共规则：18—35岁20倍、36—45岁15倍、46—55岁10倍、56岁及以上5倍。
- 不满1周岁至16周岁的公共身高范围校验，以及16周岁（含）以下肥胖指数须在9—31的公共校验。
- 医疗险二级职业按基本保费20%加费、三级职业拒保的公共规则。
