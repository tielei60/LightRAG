投保时需分别告知"有无基本医疗保险"和"有无公费医疗"：
- 任一项为"有" → 按**有社保**计算保费；
- 两项均为"无" → 按**无社保**计算保费。

本险种需执行核心现有 **C端公共投保规则**（投保当前险种均需校验）。

## 三、核保规则

### 1. 公共核保规则

- 一般规则中的**体检、财务限额不适用**本产品；
- 该产品公共规则以下列产品核保规则为准。

### 2. 产品核保规则（不符合任一规则即拒保，不予承保）

**（1）投保关系限制**
- 投保人与被保险人的关系仅限：本人、配偶、父母、子女；其他关系（如兄弟姐妹、祖孙等）不予承保。
- 投保人与被保险人为亲子关系时，二者年龄差须在18至45周岁之间，否则不予承保。
- 受益人与被保险人的关系仅限：法定、法定继承人、本人、配偶、父母、子女；其他关系不予承保。

**（2）职业限制**
- 被保险人职业须为寿险职业等级1-4类；职业等级5类及以上不予承保。

**（3）反洗钱及风控限制**
出现以下任一情形的，不予承保：
- 投保人、被保险人或受益人与公司反洗钱冻结黑名单信息重合；
- 投保人、被保险人或受益人与公司反洗钱高风险黑名单信息重合；
- 投保人为公司高风险客户。

### 3. 累计保费限额规则

同一被保险人在公司所有当前有效及在途保单中，投保本险种的累计应交总保费按投保年龄受以下限额约束，超限不予承保：

| 被保险人年龄 | 累计应交总保费限额 |
| --- | --- |
| 出生满28日-17周岁 | ≤200万 |
| 18周岁-50周岁 | ≤400万 |
| 51周岁-60周岁 | ≤300万 |
| 61周岁-70周岁 | ≤100万 |

## 四、条款中与投保相关的约定

| 项目 | 条款约定 |
| --- | --- |
| 投保范围（条款1.3） | 被保险人投保年龄为0周岁（须出生满28日）至60周岁，且须符合投保当时公司规定 |
| 犹豫期（条款1.4） | 自签收合同之日起15日；犹豫期内解除合同，扣除不超过10元工本费后退还全部保险费（已给付保险金的需扣除） |
| 未成年人身故保额限制（条款2.2） | 为未成年人投保，被保险人成年前身故给付的保险金总和不得超过国务院保险监督管理机构规定的限额：不满10周岁不超过20万元，已满10周岁但未满18周岁不超过50万元 |
| 明确说明与如实告知（条款8.1） | 故意或重大过失未如实告知、足以影响承保决定的，公司有权解除合同；故意不告知的对解除前事故不承担保险责任且不退保费；重大过失且严重影响事故发生的，不承担责任但退还保费 |
| 年龄性别错误处理（条款8.2） | 真实年龄不符合投保年龄限制的，公司有权解除合同并退还现金价值；实付保费少于应付的，补交保费或按比例给付；实付多于应付的，退还多收保费 |
| 合同解除权限制（条款8.3） | 解除权自知道解除事由之日起超过30日不行使而消灭；自合同成立之日起超过2年的，不得解除合同 |
| 等待期 | 合同生效（或最后复效）之日起180日（含）；意外伤害导致的无等待期 |
