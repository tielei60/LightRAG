# 北京人寿京福宏运（尊享版）终身寿险（分红型）投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京福宏运（尊享版）终身寿险（分红型） |
| 销售渠道 | 中介、个险 |
| 交费方式 | 趸交、年交 |
| 交费年期 | 趸交、3年、5年、10年、15年、20年 |
| 保险期间 | 终身 |
| 保费 | 须大于0 |
| 等待期 | 0天 |
| 红利领取方式 | 累积生息、现金领取、购买交清增额保险；未选择时默认购买交清增额保险 |

## 二、投保规则

执行现有个险公共投保规则。期交须满足投保年龄＋交费年期≤70周岁。

| 交费年期 | 被保险人投保年龄 |
| --- | --- |
| 趸交 | 出生满28日（含）至70周岁（含） |
| 3年交 | 出生满28日（含）至67周岁（含） |
| 5年交 | 出生满28日（含）至65周岁（含） |
| 10年交 | 出生满28日（含）至60周岁（含） |
| 15年交 | 出生满28日（含）至55周岁（含） |
| 20年交 | 出生满28日（含）至50周岁（含） |

## 三、核保规则

### 1. 公共核保与加费

公共核保中的体检、财务限额规则不适用，按下列产品规则执行；其他个险公共核保规则继续适用。不支持健康加费和职业加费。

### 2. 体检要求

| 被保险人年龄 | 需体检的条件 |
| --- | --- |
| 不满18周岁 | 同类险种累计应交总保费超过600万元 |
| 18—40周岁，含上下限 | 超过1500万元 |
| 41—50周岁，含上下限 | 超过1500万元 |
| 51—65周岁，含上下限 | 超过1000万元 |
| 66周岁及以上 | 超过500万元 |

### 3. 财务要求

| 同类险种累计应交总保费 | 所需资料 |
| --- | --- |
| 超过1500万元 | 财务问卷，财富类公司在投资产或银行存款对账单 |
| 超过2000万元 | 上述资料，以及其他个人及企业资产证明 |

同类险种为所有增额终身寿险，包括京福传家、京福世享、京福传世爱、恒爱传世、京福悦享等系列。

应交总保费＝期交保费×交费期限。仅累计有效及在途保单，其他状态不累计。

## 四、风险保额累计

寿险、残疾风险保额分别＝本产品累计应交总保费×当前年龄身故倍比系数。仅累计有效及在途保单。

| 到达年龄 | 系数 |
| --- | --- |
| 0—17周岁 | 不计 |
| 18—40周岁 | 0.6 |
| 41—60周岁 | 0.4 |
| 61周岁及以上 | 0.2 |
