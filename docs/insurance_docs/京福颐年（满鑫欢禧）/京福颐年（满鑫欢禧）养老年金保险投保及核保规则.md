# 北京人寿京福颐年（满鑫欢禧）养老年金保险投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京福颐年（满鑫欢禧）养老年金保险 |
| 销售渠道 | 中介 |
| 可附加险种 | 无 |
| 交费方式 | 趸交、年交 |
| 交费年期 | 趸交、3年、5年、10年 |
| 保险期间 | 终身 |
| 被保险人年龄 | 出生满28日（含）至65周岁（含） |

## 二、投保规则

执行现有个险公共投保规则。

| 投保要素 | 条件 |
| --- | --- |
| 保障计划 | 计划一、计划二、计划三 |
| 年金领取频次 | 月领、年领 |
| 年金起领年龄 | 55、60、65、70、75周岁 |
| 55周岁起领 | 仅限女性 |
| 计划二保证领取期间 | 20年 |
| 年金领取止期 | 至终身 |

具体可投保年龄须与起领年龄、交费年期对应的费率条件一致。

## 三、核保规则

### 1. 公共核保与加费

执行现有公共核保规则。不支持健康加费和职业加费。

### 2. 财务要求

被保险人同类险种累计应交总保费超过1000万元，须提供财务问卷。

同类险种为所有年金类产品，包括分红及万能险。应交总保费＝期交保费×交费期限。仅累计有效及在途保单，其他状态不累计。

## 四、风险保额累计

本产品不计风险保额和体检保额。
