# 北京人寿京富添利终身寿险（万能型）投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京富添利终身寿险（万能型） |
| 销售渠道 | 个险、中介 |
| 可附加险种 | 无 |
| 投保年龄 | 出生满28天（含）至70周岁（含） |
| 保险期间 | 终身 |
| 交费方式 | 不定期交 |

## 二、投保规则

### 1. 公共投保要求

执行个险公共投保规则。既往增额终身寿保单正在办理保全的，须待保全申请结束后再投保。

### 2. 单独投保

| 情形 | 保费限制 |
| --- | --- |
| 单独投保次数 | 仅可单独投保一次 |
| 无投保人、被保险人一致的增额终身寿保单 | 首期保费不超过10000元，且为100元整数倍 |
| 有一致的、处于交费期内的趸交增额终身寿保单 | 累交保费不超过分红型增额终身寿应交保费的2倍，且为100元整数倍 |
| 有一致的、处于交费期内的期交增额终身寿保单 | 首期保费不超过分红型增额终身寿应交总保费的1倍，且为100元整数倍 |
| 一致的增额终身寿保单已过交费期 | 首期保费不超过10000元，且为100元整数倍 |

存在投保人、被保险人一致的增额终身寿保单但未关联的，仍按单独投保处理。

有多张符合条件的终身寿保单，取保费最高的一张作为上限参照；最高者已过交费期但另有符合条件且在交费期内的保单时，取这些保单中保费最高的一张。

### 3. 关联投保

| 情形 | 投保条件 |
| --- | --- |
| 首期保费 | 不低于100元，且为100元整数倍 |
| 关联趸交保单处于交费期内 | 万能险累交保费不超过对应年金分红或分红型增额终身寿险累交保费的2倍，且为100元整数倍 |
| 关联期交保单处于交费期内 | 首期保费不超过关联险种应交总保费的1倍，且为100元整数倍 |
| 关联保单已过交费期 | 首期保费不超过10000元，且为100元整数倍 |
| 关联保单已办理信托 | 不可关联 |

关联保单须满足：

- 投保人、被保险人与本保单一致，双方五要素一致。
- 属于年金险、分红险（含养老金）或分红型终身寿险，不能是当前万能险保单。
- 为已承保有效保单，或尚未处于签单环节的在途保单。
- 已承保保单的产品允许关联万能险；在途保单须选择年金或红利进入万能账户。
- 尚未关联其他保单；关联保单的销售渠道不作限制。

### 4. 抵交保费

仅同时承保且存在可关联保单时，可申请抵交关联保单保费；关联既往保单不支持该投保时抵交安排。申请抵交保费须提供《万能保险保费抵交申请书》。

## 三、核保规则

### 1. 公共核保要求

公共核保中关于“达到体检标准”和“提供财务问卷”的规则不适用，按下列产品规则执行；其他个险公共核保规则继续适用。

### 2. 体检要求

累计应交保费／保额＝所有增额终身寿险累计应交总保费＋本险种累计基本保额。契约投保时，本险种累计基本保额之和等于本产品趸交保费。

| 被保险人年龄 | 需体检的条件 |
| --- | --- |
| 不满18周岁 | 累计应交保费／保额超过1000万元 |
| 18—50周岁，含上下限 | 超过1500万元 |
| 51—65周岁，含上下限 | 超过1000万元 |
| 66周岁及以上 | 超过500万元 |

### 3. 财务与加费要求

- 被保险人累计应交总保费超过1500万元，须提供财务问卷。
- 不支持健康加费和职业加费。

## 四、风险保额累计

同一客户全渠道累计寿险风险保额，计算为：累计基本保险金额×当前年龄身故倍比系数。

| 到达年龄 | 系数 |
| --- | --- |
| 0—17周岁 | 不计 |
| 18—40周岁 | 0.6 |
| 41—60周岁 | 0.4 |
| 61周岁及以上 | 0.2 |
