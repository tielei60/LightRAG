# 北京人寿京康优护医疗保险投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京康优护医疗保险 |
| 销售渠道 | 个险 |
| 销售范围 | 全国 |
| 险种类型 | 主险、普通型医疗保险 |
| 投保人年龄 | 年满18周岁 |
| 被保险人年龄 | 出生满28日（含）至65周岁（含） |
| 交费方式 | 趸交 |
| 交费期间 | 1年 |
| 保险期间 | 1年 |
| 生效日 | 保费到账与核保通过两日期中较晚日期的次日 |

## 二、投保计划与保额

| 计划 | 保障责任 |
| --- | --- |
| 计划一 | 住院医疗保险金、住院前后门（急）诊医疗保险金 |
| 计划二 | 计划一基本责任＋住院津贴保险金 |

基本责任保额为1000元整数倍，最低5000元、最高100000元。可选住院津贴责任以住院日津贴金额确定。

## 三、保费与投保约定

保费＝基本责任保费＋可选责任保费。

### 1. 基本责任保费

按保额所在档次分段计费：

| 保额段 | 保费计算 |
| --- | --- |
| 首5000元 | 费率1 |
| 超过5000元至10000元（含）的部分 | 该部分／1000×费率2 |
| 超过10000元至20000元（含）的部分 | 该部分／1000×费率3 |
| 超过20000元至30000元（含）的部分 | 该部分／1000×费率4 |
| 超过30000元至50000元（含）的部分 | 该部分／1000×费率5 |
| 超过50000元至100000元（含）的部分 | 该部分／1000×费率6 |

各段保费相加为基本责任保费，费率按对应费率表取值。可选责任保费＝住院日津贴／10×对应费率。

### 2. 免赔额与给付比例

- 医疗责任约定年免赔额可选0、100、200、300、500、1000元。
- 住院前后门（急）诊责任与住院责任采用同一约定年免赔额。
- 给付比例按投保时约定。
- 以基本医疗保险或公费医疗方式投保，未按该方式就诊并结算的，医疗给付比例为约定比例的60%。

### 3. 等待期

生效之日起30日内发生疾病导致的相关住院、门急诊及住院津贴责任不予承担；意外伤害按对应责任约定处理。

## 四、核保相关要求

本产品不涉及加费。
