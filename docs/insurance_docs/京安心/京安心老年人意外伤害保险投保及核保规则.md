| 项目 | 规则 |

### 2. 投保条件

- 被保险人年龄须为50—80周岁。
- 交费方式仅限趸交。
- 同一时间、同一被保险人仅可购买本产品1份。
- 交费期间须与保险期间一致。
- 保险期间须与所选计划一致。

## 三、核保规则

执行现有个险公共核保规则。

## 四、风险保额累计

同一被保险人全渠道累计，仅累计有效及在途保单，其他状态不累计：

- 基本责任保额的1倍计意外风险保额，1倍计残疾风险保额。
- 意外医疗保额与救护车费用保额的1倍，计费用补偿型医疗险保额。
- 意外住院日津贴保额的1倍，计津贴型医疗险保额。
