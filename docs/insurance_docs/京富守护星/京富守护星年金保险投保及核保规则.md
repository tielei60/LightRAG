# 北京人寿京富守护星年金保险投保及核保规则

## 一、产品基本信息

| 项目 | 规则 |
| --- | --- |
| 产品名称 | 北京人寿京富守护星年金保险 |
| 销售渠道 | 个险 |
| 可附加险种 | 无 |
| 交费方式 | 趸交、年交 |
| 交费年期 | 趸交、3年、5年 |
| 保险期间 | 终身 |

## 二、投保规则

### 1. 保障计划与领取安排

| 要素 | 规则 |
| --- | --- |
| 计划一投保年龄 | 出生满28日（含）至65周岁（含） |
| 计划二投保年龄 | 出生满28日（含）至60周岁（含） |
| 年金领取频次 | 月领、年领 |
| 年金开始领取日 | 第5或第10个保单周年日 |
| 年金领取止期 | 至终身 |

计划、起领日、交费年期及投保年龄须符合对应费率表的组合要求。执行现有个险公共投保规则。

### 2. 特定人群与证明材料

- 无民事行为能力人只能投保计划二。
- 被保险人不满8周岁，只能选择计划二，并按无民事行为能力人投保。
- 投保本产品须提供被保险人合法有效的残疾证明材料。
- 无民事行为能力人且年龄大于8周岁，须提供相应证明材料。

## 三、核保规则

### 1. 公共核保与人工审核

- 执行现有个险公共核保规则。
- 本产品须强制进行人工核保。
- 投保人或被保险人既往投保过本产品，再次投保其他险种时须人工核保；既往范围包括所有在途及已承保保单。
- 不支持健康加费和职业加费。
- 本产品适用公共健康告知要求。

### 2. 财务要求

被保险人同类险种累计应交总保费超过1500万元，须提供财务问卷。

同类险种为所有年金类产品，包括分红及万能险。应交总保费＝期交保费×交费期限。仅累计有效及在途保单，其他状态不累计。

## 四、风险保额累计

本产品不计风险保额和体检保额。
