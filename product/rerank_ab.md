# Same-candidate rerank A/B harness

This standalone experiment does not change LightRAG core, ingest documents, start
a server, or modify an existing knowledge base. Do not run it against a live
storage directory. `prepare` copies one selected local workspace twice, retains
byte-for-byte source hashes, and freezes the protocol in a private, gitignored
directory under `data/`.

## Fixed experiment

- Three independently frozen questions, with the same rubric for old questions.
- One native `only_need_prompt` retrieval per question: one keyword call and one
  batched query embedding call. Both keyword lists must be nonempty.
- Capture `_build_context_str` at entry, before reranking, `chunk_top_k`, or final
  token truncation. Store the full ordered merged candidates and graph contexts.
- Build A (rerank off) again from a deep copy. Its prompt bytes and final chunks
  must exactly match the first native result before B is attempted.
- Build B from a separate deep copy of the same candidates. A process-local
  strict rerank wrapper replaces the fallback-prone utility only for this script.
  Native final truncation, references, and rendering remain unchanged. Validate
  actual final chunk IDs against the provider's unique ranked indices.
- Fixed `mix`, `top_k=30`, `chunk_top_k=12`, token budgets 18000/4000/5000,
  `min_rerank_score=0.0`, empty history, and identical templates and graph context.
- Keyword: `qwen3.8-flash`; embedding: `qwen3.7-text-embedding-flash` (1024 dims);
  rerank: native `qwen3.7-text-rerank`, `top_n=12`, `return_documents=false`;
  answers: `qwen3.7-plus`, temperature 0, max tokens 2048, no thinking or streaming.
- Nine retrieval/rerank requests precede six answer requests. The manifest fixes
  each case/stage and alternating answer order. No stage is repeatable.

## Safety and evidence

Only `run` can create a real HTTP client. It requires an exact preflight SHA and
an independently written review JSON with `approved: true` and that
`preflight_sha256`, plus the review's own SHA. The review is not generated by this
runner. Changes to frozen code, inputs, source documents, dependencies, storage,
or public provider settings invalidate the gate before each request.

The process lock and exclusive, fsynced reservation prevent resume/replay.
Every attempt and exact request body is durably written before transmission.
There is no SDK; HTTP transport retry is zero, redirects and environment proxies
are disabled. All failures, timeouts, incomplete responses, unexpected models,
explicit refusals, thinking, malformed rankings, or stage deviations halt without
retry. A swallowed native exception cannot authorize another provider request.
The first provider failure's fixed category and integer HTTP status (or null for
unknown transport outcome) are retained in an exclusive `error.json` and the halt
summary. Later fallback attempts cannot replace that first diagnosis. No exception
message is serialized. A diagnostic write failure is reported without allowing
resume or hiding the original failure.

The existing keyword/answer cache is excluded without reading or copying its
contents. All LLM caches and the embedding cache are disabled. The 11 required
graph/vector/document/attribution storage files must remain equal in source,
copied source, and runtime inventories. A user updating the old service's cache
is not a source-data modification. No old service or old file is written.

The fixed native rerank endpoint's published limits differ slightly between
documentation pages. The harness uses conservative limits: query 4000, each
document 30000, total 120000 (query repeated per document), at most 500 documents.
The gate counts UTF-8 bytes conservatively, not exact provider tokens. No splitting
or truncation is performed to squeeze a request through the gate.

An additional process-local socket/DNS guard blocks incidental network access,
including tokenizer downloads. Only the guarded provider send temporarily opens
network access in its own execution context. Preparation loads the tokenizer
offline and records a fixed encoding probe; a missing cache blocks preparation.

Credentials are read from an explicit private environment file without dotenv
interpolation or ambient overrides, held only in memory, and never copied.
Only exact named non-secret config fields are serialized. Request and response
headers and error bodies are never saved. Successful response files preserve raw
HTTP body bytes, including all embedding vectors; metadata includes usage,
request ID, returned model presence, timestamps, and hashes. Outputs use 0600
files and 0700 directories. Never commit private experiments or local paths.

The oracle is frozen and checked but never consulted for retrieval, ranking,
prompt creation, or answer generation. Compare evidence by chunk ID, content
hash, and source hash, not by citation number. Three targeted pairs with one
generation each cannot establish stability or generalization.
The predeclared rule is to generate each arm once even if their prompt bytes are
identical. Reports contain `prompt_equal` and both prompt hashes. Answer differences
under identical prompts are generation noise, not evidence of rerank improvement.

After all 15 calls succeed, `blind-review-input.json` contains the six full
answers, their actual prompts, and source mappings in a predeclared shuffled
opaque-ID order. It omits arm labels, scores, timings, and request indices. Keep
the manifest's private ID mapping away from the independent scorer until scores
are sealed. This is practical, not cryptographic, blinding. Failed runs never
produce a complete-looking blind review bundle.

## Commands

Use the repository's supported Python environment. These placeholders deliberately
avoid committing a user's private paths.

```sh
python -m pytest product/test_rerank_ab.py -q
# Optional integration uses a private source workspace; HTTP is still mocked.
RERANK_AB_TEST_STORAGE=/private/source/workspace python -m pytest product/test_rerank_ab.py -q

python product/rerank_ab.py prepare \
  --run-dir "$PWD/data/rerank-ab/NEW-RUN" \
  --source-root /private/previous-checkout \
  --storage /private/source/workspace \
  --oracle-dir /private/frozen-oracle \
  --env-file /private/provider.env

python product/rerank_ab.py verify --run-dir "$PWD/data/rerank-ab/NEW-RUN" \
  --preflight-sha REVIEWED_PREFLIGHT_SHA256

# Only after independent review and explicit authorization to send:
python product/rerank_ab.py run --run-dir "$PWD/data/rerank-ab/NEW-RUN" \
  --preflight-sha REVIEWED_PREFLIGHT_SHA256 \
  --review-file /private/independent-review.json --review-sha INDEPENDENT_REVIEW_SHA256
```

The public test fixtures are synthetic. The optional integration reads only a
copy, uses `httpx.MockTransport`, and blocks socket connections. Focused tests
are not a claim that the repository's full test suite or live providers passed.
